# 水文数据查询程序3（Hydrological data query program3）

- 一个基于**Python + BeautifulSoup + ECharts**的便携化河道水位数据爬取与可视化展示分析程序。
- 供**梧州仓码**同事使用，快速查询梧州航道水位信息，为船舶调度提供依据。
- 是**水文数据查询程序2**的**重构轻量版**，舍弃playwright技术栈，打包的.exe程序体积大幅缩小。


## 主要功能

**1.** 爬取广西水运发展中心每日发布的官方航道水情信息，涵盖梧州仓码上游西江流域内6个水文站点与3个通航水利枢纽的水位相关数据。  
**2.** 存储每日的航道水位与水利枢纽相关数据到本地，本地化持久存储。  
**3.** 将爬取到的航道水位数据可视化展示，并做分析，初步预判近日梧州航道水位变化情况。   
**4.** 对爬取到的水位数据进行分析，并进行相关预警信息的显示，比如高水位、水位超警、放水预警。   
**5.** 支持将.py文件打包为.exe程序，可以在其他电脑更方便的使用。


## 使用说明（打包后）

**所有操作仅在"西江水位查看分析"文件夹内操作使用即可**  
**1.** 打开文件夹（西江水位查看分析）后，**双击运行"水位数据爬取.exe"文件。**  
**2.** 会打开一个终端页面，**请耐心等待10秒左右**，程序会开始自动运行。    
**3.** 程序开始自动运行后，**终端页面会输出水位信息以及运行情况**，可以通过终端判断是否运行正常。   
**4.** 运行完成后，终端会自动关闭。并且**会在程序同文件夹内生成一个"water_level_report.html"网页文件，双击打开（用浏览器打开）即可查看可视化报告。**


## 注意事项

- **在每天上午10点之后运行，以避免数据爬取不全的情况。**
- **一天内，如果已经更新了当天的数据，不需要再次运行。**
- **可视化报告在程序同文件夹内，文件名为water_level_report.html。**
- **为达到最佳展示效果，请将浏览器窗口扩展至全屏查看可视化报告。**
- **数据缺失问题：数据源链接为https://www.gxghj.cn/c/fw/slcx   打开后看到的前4条链接中，只要缺少南宁、柳州、梧州的3个航道水情信息的任意一个链接，就会影响数据爬取，导致数据缺少。**
- **使用前确保river.jpg、water_level_data.json两个文件在同文件夹内！否则可视化报告不能正常显示！**


## 项目架构

```
西江水位查看分析/
├── 水位数据爬取.exe            # 主程序，勿动！（爬取、解析、存储、生成报告）
├── water_level_data.json      # 水位与枢纽历史数据，勿动！（本地持久化存储）
├── water_level_report.html    # 可视化分析报告，勿动，每次运行自动更新！（在这看报告）
├── river.jpg                  # 流域示意图，勿动！（报告内嵌图片）
└── 使用说明.txt                # 使用说明文档
```
